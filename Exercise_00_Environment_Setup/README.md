# Exercise 0 — Environment Setup & Verification

Run `verify_environment.ipynb` to confirm your Python environment is ready.

## What Gets Checked

1. **Python version** — 3.10+ required
2. **Core libraries** — numpy, scipy, matplotlib
3. **Control systems** — python-control
4. **Visualization & interactivity** — plotly, ipywidgets, sympy, anywidget
5. **Smoke test** — builds a small system and renders an interactive plot

## If Something Fails

```bash
pip install -r ../requirements.txt
```

Then restart your Jupyter kernel and re-run the notebook.
