# Exercise 7 — Faults vs Disturbances

Learn to distinguish different causes of abnormal control system behavior.

## What's Inside

| File | Purpose |
|------|---------|
| `faults_vs_disturbances.ipynb` | Main notebook — six fault/disturbance scenarios compared |

## Scenarios Covered

| Scenario | Root Cause Category |
|----------|-------------------|
| Nominal | Baseline reference |
| Heavy load | Disturbance |
| Increased friction | Degradation / fault |
| Sensor bias | Sensing problem |
| Weak actuator | Actuator fault |
| Time delay | Control / communication issue |

## Learning Objectives

- Recognize response signatures for different failure modes
- Distinguish disturbances from faults from sensor problems
- Recommend appropriate actions (monitor, retune, inspect, maintain)
