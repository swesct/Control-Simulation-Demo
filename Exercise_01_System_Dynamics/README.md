# Exercise 1 — System Dynamics

Understand how physical systems behave before adding any control.

## Notebooks (run in order)

| # | Notebook | Topic |
|---|----------|-------|
| 1 | `01_first_order_dynamics.ipynb` | Thermal process time constant |
| 2 | `02_second_order_axis_model.ipynb` | Mass-spring-damper axis, natural frequency, damping ratio |
| 3 | `03_damping_sweep.ipynb` | Under-, critically, and overdamped comparison |
| 4 | `04_step_response_metrics.ipynb` | Rise time, settling time, overshoot, steady-state error |

## Learning Objectives

- Model first and second order dynamic systems
- Identify natural frequency and damping ratio from system parameters
- Predict how damping affects transient behavior
- Measure standard step response performance metrics
