# Exercise 3 — Digital Control & Practical Limits

Explore what happens when control meets real-world constraints.

## Notebooks (run in order)

| # | Notebook | Topic |
|---|----------|-------|
| 8 | `08_discrete_time_pid.ipynb` | Sampled control loop, sample-time effects |
| 9 | `09_actuator_saturation.ipynb` | Torque/force limits and clipping |
| 10 | `10_anti_windup.ipynb` | Integrator windup and the fix |
| 11 | `11_sensor_noise.ipynb` | Noise effect on derivative action |

## Learning Objectives

- Implement a discrete-time PID controller
- Observe how sample rate affects control quality
- Understand actuator saturation and its impact on performance
- Diagnose and fix integrator windup
- See how sensor noise degrades derivative-based control
